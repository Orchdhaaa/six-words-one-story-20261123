A complete story in exactly six words: "He proposed. She laughed. He stayed." A proposal, a laugh, and a decision to stay — a whole relationship arc in six words, with the reason for the laugh left for the reader to fill in.

## Run it

```sh
node main.ts
```

`main.ts` writes the six-word story to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), verifying first that it is exactly six words and 1–60 characters with no dash.
